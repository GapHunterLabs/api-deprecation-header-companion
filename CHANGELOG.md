# API Deprecation Header Companion Changelog

## [Unreleased]

## [0.1.1]

### Fixed

- Review/star CTA now links to this plugin's own Marketplace
  reviews page instead of the vendor's generic plugin list.

## [0.1.0]

### Added

- Gutter warning icon on any Java/Kotlin Spring MVC endpoint method
  marked `@Deprecated` whose body never sets a deprecation-related HTTP
  response header (RFC 9745 `Deprecation`, RFC 8594 `Sunset`, or
  `X-Deprecated`).
- 100% static text/PSI analysis, Java and Kotlin, no network calls, no
  telemetry. Free.
